## Customer Churn Prediction (End-to-End ML Project)

This project predicts customer churn using machine learning and demonstrates
the full data science workflow:

- Exploratory Data Analysis (EDA)
- Data preprocessing & feature engineering
- Model training and evaluation (Logistic Regression, Decision Tree, Random Forest, XGBoost)
- Threshold tuning to optimize business outcomes
- Deployment using Streamlit for interactive predictions

The Streamlit app allows users to adjust the churn probability threshold,
highlighting business-driven decision making over raw accuracy.
